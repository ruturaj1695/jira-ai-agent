# RTB Jira AI Agent

AI agent system for the RTB Cycle 16 challenge: Agentic AI - Building AI Agents (Basic).

## Goals
- Answer natural language questions on Jira-like data
- Generate sprint and team reports
- Use router + worker agent architecture
- Support RAG, tools, evaluation, logging, and deployment

## Current status
Scaffold created. Implementation is being added in phases.

## Planned stack
- Python
- FastAPI
- LangChain
- CrewAI or LangGraph
- ChromaDB
- OpenAI / Groq / Anthropic compatible LLMs
- LangSmith / logging
- Docker

## RTB reference
The RTB document expects foundations, prompt engineering, RAG, LangChain, agents, enterprise guardrails, and a Jira agent case study. This repo is organized to match that flow.
